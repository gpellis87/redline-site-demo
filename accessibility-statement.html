Accessibility Statement

Redline Site Services is committed to making this website usable by as many people as possible, including people who use assistive technology such as screen readers, keyboard-only navigation, or browser accessibility settings.

Last updated: July 30, 2026

Conformance Standard

We have worked to align this website with the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA, the standard most commonly referenced for web accessibility, including under the Americans with Disabilities Act (ADA). This statement describes our current conformance status; it is not a guarantee of full, perpetual conformance on every page.

Measures We've Taken

Work completed on this site includes:

  • Text and background color combinations checked and adjusted to meet minimum contrast ratios
  • Descriptive alternative text on informative images
  • Form fields with properly associated labels
  • A logical heading structure and a single <main> landmark on every page
  • A "skip to main content" link for keyboard users
  • Visible keyboard focus indicators on interactive elements
  • Semantic markup for navigation, buttons, and expandable content (such as FAQ accordions), with correct ARIA states
  • Removal of duplicate/redundant links so the same destination isn't announced twice in a row

How We Test

We test using a combination of automated tools - including WAVE and axe, two of the most widely used accessibility evaluation engines - and manual review of contrast, keyboard navigation, and screen reader behavior. Automated tools catch a large share of issues but not all of them, so we treat their output as a starting point rather than a final answer.

Known Limitations

Some content is provided by third parties we don't control directly, including the embedded Google Maps location and the hCaptcha spam-prevention widget on our contact form. We've configured these as accessibly as each service allows, but we can't guarantee their internal behavior meets the same standard we hold the rest of the site to.

Ongoing Commitment

Accessibility is an ongoing effort, not a one-time project. As we add pages or update the site, we aim to maintain this same standard, and we periodically re-test using the tools described above.

Reporting a Problem

If you encounter a barrier using this website, please let us know so we can address it. Call us at (704) 562-9922 or reach out through our contact form. Please include the page URL and a description of the issue if possible.
